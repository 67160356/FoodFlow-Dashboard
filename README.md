# FoodFlow Thailand Dashboard
ครอบคลุมครบ 77 จังหวัดของประเทศไทย พร้อมแผนที่ยอดขายรายจังหวัด
และตัวกรองภูมิภาค/จังหวัด/หมวดสินค้า/ประเภทลูกค้า

เปิดใช้งาน:
1. python -m pip install -r requirements.txt
2. python -m streamlit run app.py
3. เปิด http://localhost:8501

ข้อมูลเป็น Synthetic Data สำหรับโครงงาน ไม่ใช่ยอดขายจริง
